# 🍽️ AI Restaurant planner

An interactive, AI-powered restaurant planner and menu matrix built using **Streamlit**, **LangChain**, and **Groq (Llama 3.1)**. This tool helps food entrepreneurs, chefs, and culinary students instantly brainstorm cohesive restaurant concepts, dynamically generate localized pricing structures, and view ingredient breakdowns on demand.

## ✨ Features
* **Smart Location Selector:** Automatically detects and applies country-specific contexts and currency formatting (₹, $, £, €) to menu items.
* **Vibe & Theme Tuning:** Changes the naming conventions and food suggestions based on the restaurant style (e.g., Fine Dining, Trendy Cafe, Street Food).
* **On-Demand Ingredient Breakdown:** Uses interactive expanding blocks to fetch specific dish recipes without overloading the UI layout.
* **Portable Menu Downloads:** Generates instant text file exports of your finalized menu drafts for business planning.

## 🛠️ Technology Stack
* **Frontend UI:** Streamlit
* **LLM Orchestration:** LangChain Core
* **AI Model Inference:** Groq Cloud (`llama-3.1-8b-instant`)
